# vrctt-supporters

VRChatワールド **VRC卓球 (VRCTableTennis)** の支援者名簿の**記録用リポジトリ**です。

## 配信元はここではありません

ワールドが実際に読んでいるのは Cloudflare Worker です。

```
https://vrctt-supporters.gutty5128.workers.dev/v1/supporters.txt
```

GitHub Pages を経由すると、コミット後のビルド（20秒〜2分）とCDNキャッシュ（最大10分）で
反映が遅れるため、ワールドはWorkerから直接読んでいます。

このリポジトリの `v1/supporters.txt` は**同じ内容のミラー**で、
**変更の履歴を残すため**に置いてあります。中身は同一です。

## フォーマット (v1)

TSV（タブ区切り）。1行1人。2列。

```
displayName<TAB>tier
```

| 列 | 内容 |
|---|---|
| displayName | VRChatの表示名（Discordの `/vrc登録` で本人が入力したもの） |
| tier | サブスク名。`Supporter` / `Sponsor` / `Sponsor2` |

**tier は数字ではなく名前です。** 途中に新しいサブスクを挟んだとき、更新前のワールドが
番号を別のサブスクと取り違えるのを避けるためです。
サブスクの上下関係はワールド側（`SupporterManager.tierIds`）が持ちます。
ワールドが知らない名前が来た場合は「一番下相当」として扱われます。

- `#` で始まる行はコメント（ヘッダ情報）。`# count: N` に行数が入ります。
- 空行は無視。
- 改行コードは **LF**。文字コードは **UTF-8**。
- パスに `/v1/` を含めることで、将来フォーマットを変更しても旧バージョンのワールドが壊れないようにしています。

### 生成側が保証していること

1. **1つの表示名につき必ず1行**。大文字小文字を無視して突き合わせ、**上のサブスクが勝つ**
2. 表示名に**タブ・改行・制御文字は含まれない**（登録時に拒否）
3. 表示名は `#` で始まらない（コメント行に化けるため）
4. **サブスクごとにまとまっていて、上のサブスクから順**。各グループ内は表示名の昇順
5. 照合の正規化は「前後の空白を落として大文字小文字を無視」。ワールド側の `SupporterManager` と同一

## 生成の仕組み

Cloudflare Worker が以下を突き合わせて名簿を作ります。

1. **Discordのロール** — Patreon公式のDiscord連携が、ティアに応じたロールの付与・剥奪を自動で行う。支払いが止まればロールが外れ、次の実行で名簿から消える
2. **Cloudflare KV** — Discordの `/vrc登録` で本人が登録したVRChat表示名
3. **手動リスト** — Discordにいない支払い者。期限付きの指定も可能

Patreon以外で支払った人には、Patreonに紐付いていない「(個別)」ロールを手で付けます。
名簿には通常枠と同じサブスク名が入り、**ワールドは手動かどうかを区別しません。**

作り直されるきっかけは3つ。

| きっかけ | 反映まで |
|---|---|
| `/vrc登録` が実行された | その場 |
| 定期実行 | 5分以内 |
| 運営が手動で叩いた | その場 |

中身が変わらないときはコミットしません。Patreon API も GitHub Actions も使っていません。

## プライバシーについて

このファイルに含まれるのは **本人がDiscordの `/vrc登録` で自分で入力したVRChat表示名のみ** です。
DiscordのユーザーIDやユーザー名、Patreonのアカウント情報、メールアドレス等は一切含まれません。
登録コマンドの応答文にも「入力した表示名は公開名簿に掲載されます」と明記しています。

## 注意

この判定は**クライアントサイドのみ**で行われ、技術的には改ざん可能です。
解放してよいのは**見た目の特典のみ**で、ゲームバランスに影響する要素は載せません。
