# vrctt-supporters

VRChatワールド **VRC卓球 (VRCTableTennis)** の支援者名簿を配信するための公開リポジトリです。

## 配信URL

```
https://gutty007.github.io/vrctt-supporters/v1/supporters.txt
```

ワールド側は `VRCStringDownloader` でこのURLを取得し、ローカルプレイヤーの表示名と照合して特典を解放します。

## フォーマット (v1)

TSV（タブ区切り）。1行1人。

```
displayName<TAB>level<TAB>skinId
```

| 列 | 内容 |
|---|---|
| displayName | VRChatの表示名（Discordの `/vrc登録` で本人が入力したもの） |
| level | `1` = サポーター / `2` = スポンサー。数値なので「N以上」で判定できる。将来 3, 4 が増えても壊れない |
| skinId | 解放するスキンのID。複数はカンマ区切り。指定なしは `-` |

- `#` で始まる行はコメント（ヘッダ情報）。
- 空行は無視。
- 改行コードは **LF**。文字コードは **UTF-8**。
- パスに `/v1/` を含めることで、将来フォーマットを変更しても旧バージョンのワールドが壊れないようにしています。

### 生成側が保証していること

ワールド側は**自分の行を見つけた時点で走査を打ち切る**実装なので、以下は生成側の責任で担保しています。

1. **1つの表示名につき必ず1行**。大文字小文字を無視して突き合わせ、`level` は最大値、`skinId` は和集合にまとめる
2. 表示名に**タブ・改行・制御文字は含まれない**（登録時に拒否）
3. 表示名は `#` で始まらない（コメント行に化けるため）
4. 照合の正規化は「前後の空白を落として大文字小文字を無視」。ワールド側の `SupporterManager` と同一

## 更新方法

Cloudflare Worker が1時間ごとに以下を突き合わせて `v1/supporters.txt` を生成し、このリポジトリへ直接コミットします。

1. **Discordのロール** — Patreon公式のDiscord連携が、ティアに応じたロールの付与・剥奪を自動で行う。支払いが止まればロールが外れ、次の実行で名簿から消える
2. **Cloudflare KV** — Discordの `/vrc登録` で本人が登録したVRChat表示名
3. **手動リスト** — Discordにいない支払い者や、特別に配るスキン。期限付きの指定も可能

中身が変わらないときはコミットしません。

Patreon API は使っていません。GitHub Actions も使っていません。

## プライバシーについて

このファイルに含まれるのは **本人がDiscordの `/vrc登録` で自分で入力したVRChat表示名のみ** です。
DiscordのユーザーIDやユーザー名、Patreonのアカウント情報、メールアドレス等は一切含まれません。

登録コマンドの応答文にも「入力した表示名は公開名簿に掲載されます」と明記しています。

## 注意

この判定は**クライアントサイドのみ**で行われ、技術的には改ざん可能です。
解放してよいのは**見た目の特典のみ**で、ゲームバランスに影響する要素は載せません。
